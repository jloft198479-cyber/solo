极简，是一种克制的自由

写于一个安静的午后 · 关于 solo 与写作本身

好的编辑器应该像一张干净的纸：你几乎感觉不到它的存在，却又在每一个需要的瞬间，恰好出现在手边。solo 想做的，就是这样的东西。

为什么是「顶栏」

顶栏是窗口的脸面，也是你每天抬头十几次会看到的地方。它不该喧宾夺主，但也不该寡淡到没有存在感。当前这版太「隐形」了——36px 的平条，和背景几乎融为一体。

质感不是堆砌，而是让每一处细节都「说得通」。

优化想解决什么

  • 无圆角：全直角硬朗，统一克制
  • 拉高：36px → 52px，上下更舒展
  • 材质：毛玻璃让顶栏「浮」在文档之上
  • 识别：直角品牌标记 + 提亮的文件名
  • 反馈：激活态用底部细线指示，而非色块

一段示例代码

function greet(name: string) {
  // 极简，但不简单
  return `你好，${name}。开始写吧。`;
}

向下滚动，留意顶栏的玻璃质感——半透明的它，会透出你正写到的文字边缘。这正是「浮起来」的感觉。
