## 四、上线路径二选一

| 方案 | 做法 | 代价 |
|---|---|---|
| **A 静态托管（推荐）** | CNB Pages / GitHub Pages / Vercel / 对象存储 + CDN，整目录上传即可，零服务器改动 | 境外节点国内访问不稳；若用国内对象存储 + CDN，域名仍需 ICP 备案 |
| **B 宝塔建站** | 面板新建纯静态站点（**不需要 PHP / 数据库**）→ 绑域名 → 申请 Let's Encrypt → 上传文件 | 必须先修 API 白名单 IP；域名需在阿里云 DNS 加 A 记录 |

> ⚠️ 备案提醒：服务器在天翼云武汉（大陆）。用**新域名** → 必须 ICP 备案（通常数天到 20 天）；用已备案的 `weimabbs.com` 子域 → 免备案，最快。
