> 本文件是**内容素材**，不是网站方案。不含页面结构、导航、配色、布局规划。
> 第三方可直接从中取文案、特性描述、技术参数。所有内容均基于 solo 真实已实现能力整理（核对于 `docs/FEATURE-MATRIX.md` 与 `README.zh-CN.md`），未实现功能已明确标注。

## 一、产品一句话定位（多个版本，供挑选）

- 主定位：**solo —— 本地优先、极简沉浸的 Markdown 编辑器。**
- 气质版：**一把为文字而生的手术刀：秒开秒关、书卷气质、本地文件、不作生态。**
- 场景版：**写给"只想安静把字写好"的人——打开就是写，关掉就是存。**
- 反差版：**不是笔记软件，不是知识库。它只做一件事：让你和 Markdown 相处得更舒服。**
- 极简版：**solo = 一个窗口 + 一个 .md 文件 + 你。**

---

## 二、产品理念与价值观（品牌故事底稿）

solo 的出发点很简单：市面上大多数"写作工具"都在越长越大——笔记、知识库、协作、AI、云同步……功能堆成山，可你只是想写一段字、读一篇文档。

solo 选择反过来走：

1. **本地优先，文件属于你。** 文稿就是硬盘上的一个 `.md` 文件，不锁进私有数据库，不依赖云端。换电脑、换软件，双击就能打开。
2. **阅读即写作。** 没有"编辑态 / 预览态"的割裂，输入即所见，屏幕上看到的就是最终的样子。
3. **克制即体验。** 不堆功能、不弹引导、不抢注意力。能一眼看懂的，绝不埋进菜单。
4. **书卷气质。** 排版、留白、主题都为"长时间阅读不累"调过，像一本排好版的书，而不是一个填满按钮的软件界面。
5. **开源透明。** 基于 Apache 2.0 开源，代码可查，路线可议。

一句话精神：**solo 不替你管理知识，它只负责让你把眼前的字，写得舒服、存得安心。**

## 三、目标用户画像（写给文案参考）

- **个人写作者**：博客作者、自媒体人、日记党、随笔爱好者——重视"写的时候心情好"。
- **技术人**：习惯 Markdown，要写带代码、公式、图表的文档，讨厌分栏预览和格式打架。
- **注重隐私的人**：不想把文稿交给某个云笔记厂商，文件要攥在自己手里。
- **极简主义者**：受够臃肿 All-in-One 工具，想要"打开就能写、关掉就走人"的轻量体验。
- **不合适的用户（也请如实说）**：需要多人实时协作、需要知识库网状关联、需要手机端随时记——这些不是 solo 的方向。

## 四、核心特性详述（建站主内容）

> 每条都给出"是什么 + 对你有什么用"，可直接当特性卡片文案。

### 4.1 写作体验

**所见即所得（无分栏预览）**
基于 TipTap / ProseMirror 引擎，输入即渲染。你打 `# 标题`，它立刻变成标题；你打 `**粗体**`，它立刻变粗。没有左边写源码、右边看预览的割裂感，也没有"切到预览模式才能看效果"的打断。

**多窗口，各写各的**
每篇 `.md` 一个独立窗口、独立会话。可以左右并排对照两篇稿子，切窗口内容不丢，关最后一个窗口也不会误退出整个程序。

**斜杠命令（Slash Menu）**
输入 `/` 唤起命令菜单，快速插入标题、列表、代码块、表格、Callout、公式、图表等。支持中文前缀触发，代码块内自动不弹。

**Emoji 快捷输入**
输入 `:` 触发 Emoji 候选，边打边搜，回车即插入。

**互链自动补全（`[[` ）**
输入 `[[` 自动列出同目录下的 Markdown 文件，选中即生成 WikiLink 互链；链接到不存在的文档时，可一键创建。把零散的 `.md` 连成你自己的小知识网。

**查找 / 替换**
`Ctrl+F` 查找、`Ctrl+H` 替换，命中处高亮，长文档也不卡。

**焦点模式**
开启后，只有当前段落是"实"的，其余文字整体变淡。世界安静下来，你只看得见正在写的这一句。

**大纲面板**
实时提取文档标题层级，`Ctrl+/` 开合。长文导航、跳转章节，一目了然。

**列表幕布式折叠**
鼠标悬停列表行左侧箭头，即可折叠/展开该项下的全部子层级——像幕布一样把细节收起来，只看骨架。折叠状态按文档记忆。

**字数统计**
状态栏实时字数，大文档自动降级显示（带 `≈` 前缀），不卡输入。

**命令面板**
`Ctrl+K` 唤起，最近打开的文件、各类操作集中检索，键盘流友好。

**粘贴即转换**
从别处复制来的 Markdown 文本，粘贴进 solo 自动转成渲染后的内容；从网页/微信复制的内容，尽量还原成干净的 Markdown 结构。

### 4.2 阅读体验

**阅读位置记忆**
重开文档、或切走再切回，自动回到你上次停留的位置。关窗强制落盘，下次接着读。

**最近文件快开**
`Ctrl+K` 面板首组即"最近文件"，点击直达，无需在文件夹里翻。

**书卷气排版**
行高、段距、字距、留白都为长时间阅读调校过。不是把字堆满屏，而是像排过版的书。

**主题跟随系统**
支持跟随系统明暗切换；明/暗各自独立保存，不黑屏、不闪烁。

### 4.3 语法与格式能力（Markdown 全谱）

solo 支持 CommonMark 基线 + 一整套扩展语法，且**高度保真**——你写进去的格式，保存后再打开不会丢、不会变。

- **基础格式**：粗体、斜体、删除线、高亮、行内代码（可与粗斜体共存）、上标、下标、文字变浅（Dim）。
- **标题**：H1–H6，语义化。
- **列表**：无序、有序、任务清单（可嵌套）、同层混排（任务项和普通项可混在一层里，内容不丢）。
- **引用块**：标准 blockquote，支持嵌套。
- **代码块**：语法高亮 + 语言标签，高亮配色随主题走。
- **表格**：GFM 管道表格，支持对齐（左/中/右）。
- **分割线**：水平分隔线。
- **链接**：`Ctrl+单击` 直接打开；非安全协议会提示。
- **脚注**：`[^1]` 脚注引用 + 文末定义，自动归位。
- **Frontmatter**：文档头部的 YAML 元数据，读取/还原不污染正文。
- **KaTeX 数学公式**：行内 `$...$` 与块级 `$$...$$`，懒加载，不拖慢打开速度。
- **Mermaid 图表**：在编辑器里直接画流程图、时序图、脑图等。（小提示：节点 label 含中文/特殊字符时，请写成 `A["文本"]` 形式。）
- **Callout 标注块**：12 种类型、8 套配色（提示 / 注意 / 警告 / 示例 / 引用 / 成功 等），让重点一眼可见。
- **WikiLink 互链**：`[[文件名]]` 双向链接，补全、跳转、不存在则创建、拖文件入文即成链。
- **图片节点**：支持私有尺寸语法 `![alt|宽x高](src)`，按你想要的大小显示。

> 保真说明（可作技术信任背书）：solo 有一整套 round-trip 测试网（手写用例 + CommonMark 规范 + 模糊测试 + 全仓保真体检），专门防止"保存后格式悄悄变样"。粘贴进来的内容、复制出去的内容，都跑过专有的转义契约，不会凭空多出反斜杠或星号。

### 4.4 主题与排版

- **8 套内置主题**：书卷气、夜读墨色、素笺、朱墨、朱墨暗、纸白、黛青、藕荷——覆盖日间书写与夜间阅读。
- **自定义主题**：可新建、导入、导出主题，调性格差异字段（主色、底色、强调等），共享排版值走统一基线。兼容旧版双色主题格式。
- **字号 / 行高手动调节**：不想用主题默认？自己拉。
- **6 款字体（5 款按需下载）**：系统默认 + 思源宋体 / 朱雀仿宋 / 小赖字体 / 霞鹜文楷 / 汇文明朝，精选字体用到才下载，不占初始体积；字体加载双通道（CSS 优先 + 字节兜底），断网也能渲染。
- **全格式色走主题 token**：代码高亮、公式、图表配色都跟随主题，不会出现"切了暗色主题、代码块还是刺眼白底"的违和。

### 4.5 图片与媒体

- **粘贴 / 拖入图片**：从剪贴板或文件管理器直接丢进文档，自动落盘到可配置的本地目录。
- **远程图片本地缓存**：联网图片自动下载到本地缓存（≤10MB），离线也能看。
- **图片预览 + 全屏**：双击图片进预览，再进全屏浮层细看。
- **中文 / 空格文件名**：图片名带中文或空格，重开文档不丢、不错位。
- **路径安全**：严格校验图片读取路径，防止越权读取你磁盘上的其他文件。

### 4.6 窗口与系统集成（桌面原生）

- **无边框窗口 + 自定义标题栏**：干净利落，双击标题栏最大化。
- **多窗口独立进程**：每篇文档一个窗口，互不干扰。
- **窗口置顶 / 标题栏自动隐藏**：专注时把其他东西压到后面，或把标题栏收起来。
- **窗口尺寸 / 位置记忆**：关了再开，窗口还在老地方。
- **全屏**：`F11` 进入纯净全屏。
- **右键新建 .md**：在设置里开启 Windows 文件关联后，资源管理器右键即可新建。
- **错误边界**：编辑器万一异常，不会白屏崩溃，而是局部兜底。
- **内存克制**：失焦窗口自动降级 WebView2 内存占用，多开不爆内存。

### 4.7 数据安全与"文件属于你"

这是 solo 和普通云笔记最不一样的地方，值得重点讲：

- **本地文件，不上云**：文稿就是 `.md`，存在你指定的文件夹，solo 不替你上传任何东西。
- **原子写**：保存时先写临时文件再原子重命名，避免"写到一半断电/崩溃把原稿写坏"。
- **保存冲突检测**：如果文件在外部被改了，solo 弹窗让你确认"强制覆盖"还是保留，绝不静默覆盖你的稿子。
- **外部修改提示 + 重载**：别的程序改了正在编辑的文件，solo 会提醒你，并可安全重载。
- **改名同步入链**：重命名文档时，同目录内的 WikiLink 互链可批量更新（带预览确认，原子改写）。
- **格式保真防线**：见 4.3 末尾，专防"保存后内容偷偷变样"。

> 诚实说明（避免误导）：solo **默认不开启自动保存**（可在设置开启，默认间隔 30 秒，下限 5 秒）。它也不提供"崩溃会话自动恢复"——目前的兜底只是崩溃残留的临时文件，不会主动提示恢复。如果你习惯随手关，建议打开自动保存。

### 4.8 复制与输出

- **复制为 Markdown 源码**：`Ctrl+Shift+M` 一键复制纯 Markdown 源码，粘到别处编辑器原样可用。
- **复制为富文本 HTML**：状态栏复制按钮同时写入 `text/html`（渲染后的富文本）和 `text/plain`（Markdown 源码），粘到支持富文本的地方（如微信后台、Notion）即所见即所得。
- **选区含专有节点自动降级**：复制的选区里若含公式 / 图表 / 互链 / 脚注等别家不认的语法，自动回落为 Markdown 源码，保证粘出去不报错、不丢结构。
- **表格跨格复制**：表格单元格复制自动压平为 TSV，可贴进 Excel / 飞书表格。

> 诚实说明：**solo 当前没有"导出 PDF / 导出 HTML 网页"功能**（该导出系统已于较早版本移除）。需要导出时，用"复制为富文本 HTML"贴到目标工具，或用"复制为 Markdown"交给其他转换器。这一点请在官网如实标注，别承诺没的功能。

### 4.9 更新

- **启动自动检查更新**：可在"关于"页关闭。
- **手动检查更新**：菜单一键检查，有新版只提示"去软件里更新"，不打扰、不弹广告。
- **更新失败静默降级**：检查更新出错时安静跳过，不弹错误框烦你。

## 五、性能（写给在意卡顿的人）

- **秒开秒关**：基于系统 WebView2，安装包轻量，不塞私有内核。
- **大文档不卡**：10 万字级文档输入不卡顿；大文档自动启用 `content-visibility` 渲染优化、字数统计降级显示。
- **编辑器懒初始化**：没聚焦的窗口不急着建编辑器，省资源。
- **公式 / 图表懒加载**：解析时只分词不渲染，保住打开速度。
- **切文件不重建编辑器**：实例复用，切换文档只换内容，不重新加载整套引擎。

## 六、技术架构（写给技术向访客 / 开发者）

- **外壳**：Tauri 2（Rust）——轻量、安全、原生系统集成。
- **前端**：Vue 3 + Pinia + TipTap / ProseMirror + Tailwind CSS。
- **分层**：前端业务统一通过 `services/tauri/` 封装调用 Rust 命令；Rust 侧返回结构化 DTO 与 `AppError`。
- **通用能力优先用 Tauri 官方插件**，不自造轮子。
- **质量防线**：改解析/序列化/ schema 前必跑多套保真测试网（round-trip / fixtures / fuzz / CommonMark / 行为矩阵 / 全仓体检），专门防"静默丢内容"这类最贵的事故。
- **开源**：Apache 2.0。仓库：github.com/jloft198479-cyber/solo。

## 九、常见问题（FAQ，可作官网答疑区）

**Q：solo 是笔记软件吗？能建知识库吗？**
A：不是。solo 是单文件 Markdown 编辑器，专注"把字写好、读得舒服"。双向链接只帮你把同目录 `.md` 连起来，不做图谱、不做数据库、不做云同步。

**Q：我的文稿存在哪？会被上传到云端吗？**
A：存在你电脑上你指定的文件夹，就是一个个 `.md` 文件。solo 不会上传任何内容到云端。

**Q：会不会"保存完格式就变了"？**
A：solo 有一整套保真测试专门防这个。粘贴、复制、保存、重开的格式都经过校验契约，目标是"你写进去什么样，打开还是什么样"。

**Q：支持手机端吗？**
A：当前只发 Windows 版，手机端不在范围内。

**Q：能导出 PDF 吗？**
A：当前不能。可用"复制为富文本 HTML"贴到支持导出的工具，或用"复制为 Markdown"交给其他转换器。

**Q：自动保存开着吗？**
A：默认关闭，可在设置开启（默认 30 秒，可调）。如果你习惯随手关窗口，建议打开。

**Q：支持 Mermaid 图表吗？中文标签为什么报错？**
A：支持。节点 label 含中文或特殊字符时，请写成 `A["文本"]` 形式即可正常渲染。

**Q：闪退了写的没保存怎么办？**
A：solo 用原子写保护原稿不被写坏；自动保存开启后定期落盘。目前没有"崩溃会话恢复"，重要文稿请保持自动保存开启。
