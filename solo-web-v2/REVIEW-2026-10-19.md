## 一、代码规范与性能

### 实测数据（DPR=2）

| 场景 | 请求数 | 传输量 | FCP | 控制台 |
|---|---|---|---|---|
| 首屏 1280×900 | 6（HTML/CSS/JS/图标 + 2 张图） | 315KB | 280ms | 干净 |

| 全页滚完 1280 | 10 | 847KB | 336ms | 干净 |

文本资源 gzip 后：HTML 26.9KB + CSS 10.4KB + JS 2.4KB ≈ **40KB**。

### ✅ 做得好的

- **零外部请求**：无 CDN 字体、无框架、无第三方脚本——国内网络下这是最大优势
- **图片纪律**：`loading="lazy"` + `decoding="async"` + 显式 `width/height`（无 CLS）；暗色图 `display:none` 不参与加载
- **main.js 规范**：IIFE + `'use strict'`；scroll 监听 `passive`；IntersectionObserver 有 2.5s 兜底（防快速滚动跳过）；Tab 支持方向键/Home/End；Esc 与点外关闭菜单；`prefers-reduced-motion` 全局降级
- **可访问性**：skip-link、`aria-current`、`aria-expanded`、`:focus-visible`、12/12 图片有 alt、11/11 外链带 `rel="noopener noreferrer"`、语义地标 nav/main/footer 齐全
- **主题无闪白**：head 内联脚本在首屏前定主题（index.html:31-41）

### 🟡 P0 — 字体样张图超重（单项最大收益）

- **事实**：6 张亮色样张合计 **730KB**；每张 **2240×864**，而 2 列网格里实际显示宽度只有 **≈516px**（styles.css:548），DPR2 需要约 1032px——**多出约 2 倍线性像素**
- **实测转换**（同一批图）：
  | 格式 | 6 张合计 |
  |---|---|
  | 现行 PNG 2240 宽 | 730KB |
  | WebP q90（原尺寸） | 292KB（−60%） |
  | WebP + 降到 1120 宽（估算） | **≈80KB（−89%）** |
- **建议**：把 12 张（含暗色）先缩到 1120 宽再转 WebP（或重跑渲染脚本 `--force-device-scale-factor=1`）。全页传输可从 847KB 降到约 200KB。
- **附带**：暗色图在切主题那一刻才请求（display:none + lazy 永不进视口）→ 首次切暗色会有短暂空图；可在用户首次切主题时预加载。

### 🟡 P1 — 编辑器调试样式遗留在生产 HTML（index.html:43）

```html
<style id="__dm_no_drag_style__">* { -webkit-user-drag: none !important; }</style>
<style id="__dm_bindable_badge_style__">[data-sp-bindable="database"]{outline:1px dashed #0088ff;...}</style>
```

- 第一条**全站禁止拖拽**（图片/文字都拖不动），是一条真实的交互副作用
- 第二条是蓝色虚线框调试规则，整页无元素使用（`data-sp-bindable` 仅出现在这条样式自身）
- **建议**：发布前删除。编辑器下次保存可能重新注入，建议固化成"发布前清理"一步。

## 二、SEO 友好度

### ✅ 已到位

title（30 字，含"solo / Markdown 编辑器"）、description、`lang="zh-CN"`、单一 H1、语义地标、跳转链接、JSON-LD（SoftwareApplication + Apache-2.0 + downloadUrl）、双 `theme-color`、favicon、11 个外链均为描述性文字（无"点击这里"）

### 🟡 P0 — 缺社交分享图 `og:image`（index.html:10-11 已注释待补）

- 现状：`twitter:card=summary` 且无图 → 微信/飞书/X 分享只有一行文字，**这是"出圈"最吃亏的一项**
- 需要两样东西：① 一张 1200×630 分享图（可用现有编辑器 mock 截图 + 标语合成，本站素材齐全）② **正式域名**（og:image 必须是绝对 URL）

### 🟡 P1 — 缺 canonical / og:url

- 依赖正式域名。域名定了，两行 meta 即可（外加防止未来多域名重复收录）

### 🟡 P1 — 缺 robots.txt / sitemap.xml

- 单页站，sitemap 只需一条 URL，但**必须是绝对地址** → 同样等域名
- robots.txt 顺带写上 `Sitemap:` 行即可

### 🟡 P2 — H1 是口号，不含产品名/品类

- H1 =「克制即自由」，"solo / Markdown 编辑器"只出现在 title、badge、正文
- 建议（不动视觉）：H1 内加一个视觉隐藏的品类词（如 `克制即自由<span class="sr-only">——solo，极简 Markdown 编辑器</span>`），或把 badge 里的品类词提进 H1

### 💭 P3 — 结构化数据可补

`softwareVersion: "1.2.61"`、`offers: {price: "0", priceCurrency: "CNY"}`、`screenshot`、`inLanguage: "zh-CN"`；description 可加"开源、免费"（现在没有这两个词）
