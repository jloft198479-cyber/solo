# solo 产品官网 · 建站方案

> 目标：为 `F:\fzz-Project\md-editor`（产品名 **solo**，本地优先的极简 Markdown 编辑器）做一份「简单 · 大气 · 上档次」的产品官网。
> 本文件是方案（含视觉预览），落地前需你确认技术选型与范围。配套视觉预览：`website/index.html`（双击即开）。

---

## 一、为什么做这个官网（目标）

solo 现在只有 GitHub README，没有独立门面。一个官网要解决三件事：

1. **让人一眼看懂它是谁**：不是笔记软件、不是知识库，是一把「为文字而生的手术刀」——本地、秒开、书卷气。
2. **把下载入口和信任感做出来**：清晰的下载按钮、版本、系统要求、开源协议（Apache 2.0）。
3. **把产品的气质透出来**：极简、极速、优雅，本身就是卖点，官网自己也得长这样。

一句话定位（建议直接用在官网）：**solo — 本地优先，极简沉浸的 Markdown 编辑器。**

---

## 二、设计概念：把「简单大气上档次」翻译成设计语言

你的诉求「简单大气上档次」和 solo 自己的产品精神（极简 / 极速 / 优雅 / 书卷气质）是同一条线。所以设计方向定为一句话：

> **书卷气 · 编辑式极简（Editorial Minimalism）**——像一本装帧讲究的书，而不是一个塞满按钮的软件下载页。

具体怎么落地（避开 AI 套路审美）：

| 你要的感觉 | 设计上的做法 |
|---|---|
| **简单** | 不用花哨渐变、不用毛玻璃、不用圆角堆阴影。靠留白和一条发丝线（hairline）划分空间。 |
| **大气** | 大字号衬线标题（思源宋体 + Fraunces 英文衬线）、超大负空间、不把东西全挤在中间。 |
| **上档次** | 克制的「朱砂红」做唯一点睛色；纸张暖白底 + 墨黑字；排版有节奏、有呼吸感。 |

**配色（克制到 3–4 色）**
- 纸白底 `#F6F1E8` / 墨黑字 `#1B1916` / 朱砂点睛 `#B23A2E` / 暖灰辅助 `#8A8074`
- 暗色模式对应产品的「夜读墨色」：`#16140F` 底 / `#EDE7DA` 字 / 朱砂 `#D9543F`

**字体**
- 中文标题/正文：思源宋体（Noto Serif SC，产品自带同款字体，气质统一）
- 英文展示字：Fraunces（高对比衬线，有奢侈品编辑感，用在 `solo` 字标和大标题）
- 界面/正文辅助：思源黑体（Noto Sans SC）+ 系统字体

**节奏**：区块上下留白 `clamp(5rem,12vh,10rem)`；容器最大宽 1100px；动效只用「淡入上移 + ease-out-quart」，且尊重 `prefers-reduced-motion`。

## 四、技术选型建议（请你拍板）

| 方案 | 适合度 | 理由 |
|---|---|---|
| **① Astro（推荐）** | ★★★★★ | 内容/营销站首选，默认零 JS、加载极快（契合「极速」人设），MDX 写文案舒服，未来加博客/文档易扩展。构建产物是静态，随便托管。 |
| **② 纯静态 HTML + CSS（v1 最快）** | ★★★★☆ | 零依赖、双击即开、最贴合「极简」哲学。适合先上线一页，后期再迁移。本方案的 `index.html` 就是这种形态。 |
| **③ Next.js（网页通专家默认栈）** | ★★★☆☆ | 若你打算把官网做成带登录/交互的应用才需要；纯营销页用它是杀鸡用牛刀，且偏离「极简」。 |

**我的建议**：先用 **② 纯静态** 把这一版上线跑起来（最快见到效果、零成本），等要加文档/博客/多语言时再平滑迁到 **① Astro**。两者视觉完全通用，迁移只是换壳。

## 五、实施步骤（建议节奏）

1. **确认范围与选型**（现在）：你确认用纯静态还是 Astro，以及是否要暗色模式、多语言。
2. **视觉定稿**：以 `index.html` 为蓝本，微调配色/字体/文案，定下设计系统（色值、字号、间距）。
3. **切片落地**：把单页拆成组件/页面，补齐真实素材（产品截图、安装包直链、GitHub 动态版本号）。
4. **内容校对**：特性描述、主题名、版本号全部以 `README` / `wiki` 为准，不臆造。
5. **部署**：静态托管（GitHub Pages / Vercel / 你的宝塔服务器都行），绑定域名（你已有阿里云 DNS + 宝塔域名托管能力）。
6. **收尾**：SEO 基础（title/description/og 图）、favicon（用 `icons/icon.png`）、移动端适配复检。

## 六、边界与风险（守住「简约而不简单」）

- **不堆功能**：官网就是「让人懂 + 让人下」，不做论坛、不做登录、不做花哨动效。
- **素材不臆造**：截图/版本号/系统要求一律取自仓库真实文件；`index.html` 里的主题色是示意值，落地时以 `src/themes/` 实际值为准。
- **保持本地优先调性**：文案强调本地文件、不开云、不绑定账号，和产品的「不生态」主张一致。
- **移动端不砍功能**：响应式用容器查询，关键 CTA 在手机上照样在首屏。
