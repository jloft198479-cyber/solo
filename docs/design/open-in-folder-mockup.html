清晨五点，雾还没散。老周把最后一封信塞进帆布包，顺手把门带上。山路在脚下往前铺，像一条被雨水洗过的旧绳子。

他认得这条路。哪块石头松，哪段坡陡，哪户人家的狗只在陌生人面前叫，他都记得。可他记不住信里的字——他不识几个字，只知道把信送到。

“信到了，人就到了。”他常这么说。

A 文件菜单 + 命令面板 必做兜底

符合桌面软件习惯；不占常驻界面；命令面板可搜索，键盘用户友好。

藏得深，新用户不主动翻菜单就发现不了；Windows 无边框窗口下菜单栏是否常驻需按实机确认。

建议菜单放在「另存为...」下方加一条分隔线，命令面板同名条目同步注册。

B 状态栏文件夹图标 推荐主入口

一键直达；与主题/字体/复制/设置同构，用户已经习惯在这排找文档级动作；图标 + tooltip 成本低。

属于低频动作，会增加一个常驻图标；窄窗口下右侧图标略挤。

放在「复制全文」右侧、「设置」左侧；未保存的新文档没有路径时置灰，tooltip 提示「先保存到磁盘」。

C 标题栏标题旁 首版暂缓

上下文最强：文件身份就在旁边，悬停即现，不占状态栏。

标题点击已经用于重命名；再加 hover 按钮容易误触，也让标题栏拖拽区域更碎；触屏/键盘可达性差。

如果以后做「文档操作菜单」，可以把重命名、复制路径、在文件夹中显示收进一个入口，再考虑放在这里。

✓
建议：B 主入口 + A 兜底，C 首版不做

solo 没有标签页和文件树，状态栏是唯一常驻的「文档级操作区」，把高频可达性放在这里最顺； 文件菜单与命令面板负责可发现性和键盘路径。这样既不破坏极简界面，也不会让功能只能靠记忆找到。

边界：无路径的新文档禁用；文件被移动/删除时给出中文错误提示；多窗口只作用于当前窗口的文档； 点击后在系统文件管理器中定位并选中该文件，而不是只打开父目录。
