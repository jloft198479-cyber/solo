# solo 深度审查报告

> 审查对象：F:\fzz-Project\md-editor @ HEAD `16abf1c`（v1.2.51）。方式：只读、以代码为准，关键结论已回源码抽查验证。标尺：产品三原则「极简 / 极速 / 优雅」+ 骨架「高内聚低耦合 / 原子化组件化 / SSOT / 无僵尸代码」。

## 值得动手的问题（按对用户体验的影响排序）

### 高

1. **大纲侧栏的"当前段落高亮"可能在刚打开文档时失灵。**（结构已确认，真机待验）
   证据：`OutlinePanel.vue` 的 `attachScroll()` 在编辑器视图未就绪时直接 `return`，且只有"挂载"和"editorRef 引用变化"两个 `nextTick` 触发点，无重试；而编辑器是 `MarkdownEditor.vue` 里 rAF 懒建的，`nextTick`（微任务）早于 `requestAnimationFrame`，那一刻视图尚为 null。
   影响：若 editorRef 引用此后不再变，滚动大纲永不跟高——属"功能时好时坏"型缺陷。
   方向：把 attach 改成"视图就绪信号驱动/带重试"，而非赌微任务时序。

2. **斜杠菜单按 Esc 关闭，会顺带退出"焦点模式"。**
   证据：`editor-extensions.ts` 里 Emoji(287)、Wikilink(342) 的 Esc 都调了 `stopPropagation()` 并注释"不应顺带触发 window 级 Esc"，唯独 Slash(235-241) 漏了；`useAppDomEvents.ts` 的 window Esc 会切焦点模式。
   影响：焦点模式下关菜单会误触退模式，多一步意外。
   方向：与兄弟处理对齐加 `stopPropagation`，一行的事。

> 修订（2026-09-11 复审）：原「第 1 条·图片语法 `![..](..)` 不即时转换」经第三方审核指正并回源码复核为**假阳性**——`CustomImage = Image.extend(...)` 未覆盖 `addInputRules`，继承官方 `@tiptap/extension-image` 自带的图片输入规则（`image.ts:259` + `dist/index.js:142`），手打即转。原条目及其"新增图片 InputRule"建议一并撤销。唯一残留可留意（未验证）：官方规则正则为 `(?:^|\s)(![...])$`，要求 `!` 前是行首或空格，故紧贴中文后无空格直打可能不触发——但这是另一码事，非原结论。

### 中

3. **代码块/行内码可能被注入不可见字符（零宽连接符）。**（子代理报告，机理可信，建议复核）
   证据：CJK 边界预处理 `parser.ts:544-564` 在解析前对"整篇原文"插 `\u200C`，未排除围栏/反引号内；序列化仅在 `escapeInline` 剥离，而代码块/行内码走 `textContent` 原样写、绕过该剥离（`serializer.ts` 相应分支）。
   影响：含"中文标点+星号"等组合的代码，保存后混入肉眼不可见的脏字符，外部编辑器/比对时现形。
   方向：预处理替换范围排除 code/围栏 token（或代码分支也剥零宽符）。

4. **纯逻辑模块被放在 UI 目录下，逼出"下层反向依赖上层"。**
   证据：`composables/` 多处从 `components/Editor/…` 引入无 UI 依赖的核心逻辑（`useDocumentSession.ts:19`、`useEditorSync.ts:9-11`、`useAppWindowSession.ts:5`、`useAppEditorState.ts:4`，已确认 6 处）。
   影响：违反产品自定的"高内聚低耦合、模块可独立"骨架原则，测试/替换受阻。
   方向：把 `document-scale`/`editor-metadata`/`serializer` 等下沉到独立逻辑层（如 `src/core`），让依赖单向流动。

5. **roundtrip 测试用的是"镜像 schema"，与生产 schema 两处并行定义，造成测试盲区。**
   证据：`test-utils.ts:5 createTestSchema()` 与 `compat-schema.ts` 各一套；测试 schema 的表格/image 节点缺 colspan/rowspan、width/height 属性。
   影响：表格跨格、`![a|100x200]` 尺寸语法等 roundtrip 无覆盖，生产改属性时测试静默漂移、给"假绿灯"。
   方向：测试复用生产 schema 构造器，消分叉。

### 低

6. **打印时 mermaid/公式/代码块的顶部灰条和小标签没隐藏**：`main.css` 的 `@media print` 选择器写成了代码里不存在的类名（`grep` 可见 `.mk-mermaid-delete` 等），真实类是 `.mk-block-delete-button` 等。焦点模式变暗、减少动效等已正确覆盖，仅这块失配。

7. **首屏包体可再瘦**：`SettingsModal`、`CommandPalette`、字体相关随主包静态引入（`App.vue`），实际只在按快捷键时才打开。挪成异步即可让"秒开"再快一点——非阻塞，属锦上添花。

8. **超大文档（>50 万字）打字偶发一次掉帧**：脏态比对每次对全文做多次全量字符串处理（`useEditorSync.ts:120` + `file.ts:66-71`）。已有 heavy 档位封顶、正常/中等文档无感，性价比最高的修法是"先比长度、只裁尾部"的快路径。

## 正面确认（历史大坑已闭环，回源码核实）

命令名 SSOT 干净（全仓无绕过 `invokeCommand` 的硬编码 `invoke`）；`[[` 互链补全漏接线**已在 HEAD 修好并留防回退注释**；`!` 直输误吞守卫已加；字体 CORS/CSP、mermaid 生产黑块 CSP nonce、表格剪贴板 slice、拖拽广播 per-handler try/catch + 迭代快照、内存上界（远程图 500 条 LRU + Rust 磁盘 200MB）、大纲二分查找、减少动效无障碍底线——均已到位。几乎无注释掉的死代码、无遗留 TODO/忽略。减法纪律执行得好。
