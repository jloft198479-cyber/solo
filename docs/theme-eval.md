## 三、一致性 = 「不同模板、一套数据」

### 现状问题（真理源分裂）
- 排版变量（字距/引用边/标记圆角）在 7 个 JSON 里**手写重复、数值三套不一致**（`-0.01em/0` × `3px/2px` × `2px/3px`）
- 同一个数据被复制 7 份 → 改一处要改 7 处，必然漂移

### 方案：排版数据归一
- **排版真理源 = `editor.css` `:root` 的 `--mk-*` 默认值（唯一一份）**
- 各主题 JSON **删除 `typography` 字段**，只管颜色（唯一差异维度）
- `manager.ts` `injectTypography` 保留：有覆盖才注入，无覆盖时现有逻辑已会 `removeProperty` 回退默认 ✓ 天然兼容
- 效果：切主题只剩"换色"，排版零跳变；一致性由架构保证，不再靠人肉对齐
- 自定义主题导入不受影响（仍可带 typography 覆盖）

## 四、性能与 UI 表现力

### 性能（真优化点）
1. **主题 JSON 瘦身**：6 个 JSON 删 typography 字段，体积与解析量下降
2. **`applyTheme` 变量注入改 diff**：仅当 CSS 变量值变化才 `setProperty`（现状全量写入 → 无谓样式计算/重排），主题切换更顺

### UI 表现力
- 列表浅上深下、组内暖→冷：一眼可按亮度/色系定位
- 两个暗色冷暖分明，夜间选择有明确差异
- 灵魂主题（书卷气）在浅色组首位，气质锚点清晰
