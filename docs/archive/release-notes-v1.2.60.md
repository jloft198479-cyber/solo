## solo v1.2.60

**更新方式**：打开 solo → 设置 → 关于，点「检查更新」；或等待自动更新提示。

### 新增

- **重开文档回到上次读到的位置**：关掉再打开、或在多个窗口间切回来，自动回到你上次看到的地方。数据只存在本机，**不会写进你的文档**。
- **命令面板新增「最近文件」**（`Ctrl+K` 打开后第一组）：最近打开的 10 篇文档，点击即开；点之前仍会问你有没有没保存的内容。
- **列表行首可折叠**：带子列表的项多了折叠箭头，像大纲一样收起 / 展开。（折叠只服务列表；标题折叠此前试过一轮已撤下。）

### 改进

- 状态栏「未保存」不再固定成突兀的棕黄色，改随当前主题主色；两个状态改用**圆点形状**区分：未保存＝空心圈，已保存＝实心点。
- 「关于」并入设置中心，不再单独弹窗。
- 标题排版更贴写作手感：打标题不再像多打了一个空行，定稿瞬间不再跳一下。
- 设置页视觉清理：去掉重复文案、统一直角语言、修好快捷键布局错位。

### 修复

- **Windows 边缘 / 四角缩放不再「拉一次不动」**：改由系统原生通道接管，缩放光标、双击最大化、边缘吸附都恢复正常。
- **点正文下方的空白能放光标了**：此前点段落 / 表格 / 代码块下方的留白没反应。
- **标题栏 X 与 Alt+F4 走同一条路**：不再可能同时弹出两个保存确认框。
- 靠右的选区工具条不再溢出窗口；崩溃兜底页不再显示乱码 `[object Object]`。
- 代码块语言、提示框标题改为**就地编辑**，不再弹出空白输入框。
- 复制全文到 Word / 飞书等外部应用时，不再带出 solo 的私有标签和隐形字符。
- 一批「打开→保存会悄悄改文件」的问题：空 YAML 头整块消失、提示框与引用互相吃掉、脚注后续段落被合并、容器里的公式每次保存多缩进一层、代码围栏语言名被压成小写、强调里包行内代码时加粗丢失。
- 字数统计、大纲、纯文本复制不再被隐形字符污染。
- 编辑器里真正生效的快捷键 = 设置页里显示的键（此前部分键按了没反应，`Ctrl+Shift+S` 还会被删除线抢走）。

完整变更见仓库 `docs/CHANGELOG.md`。
