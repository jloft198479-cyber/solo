## 1. Phase 1 · 修 `[[` 弹候选接线 ✅

- **改动**：`editor-extensions.ts` `WikilinkSuggest.configure(...)` 顶层补 `getDocumentPath: () => options.getDocumentPath?.() ?? null`，把当前文档路径接进扩展级 option（`allow` 门控据此判断是否弹 `[[` 菜单）。
- **根因**：v1.2.43（`6a28edd`）引入 `[[` 补全时，`suggestion` 闭包用了 `options.getDocumentPath` 但扩展级 `getDocumentPath` 从没接，恒为默认 `()=>null` → 菜单对所有保存状态永不弹。
- **测试**：`editor-extensions.spec.ts` 加回归锁，断言 `createEditorExtensions` 产出的 `wikilinkSuggest` 扩展级 `getDocumentPath()` 返回注入路径。
- **自检**：`vitest`（wikilink/wikilink-suggest/editor-extensions 共 25 项）全绿；`vue-tsc --noEmit` 退出 0。
- **回滚**：本阶段独立提交，`git revert` 即可；未碰其它入口。

## 2. Phase 2 · 修 `![..](..)` 被链接直输误吃 ✅

- **改动**：`markdown-input.ts` `convertPendingLink` 在拿到 `match` 后加守卫——`[` 起点前紧邻字符为 `!` 时判为图片语法，直接 `return null` 不转换（与 `suggestion-guard.ts` 的 `![[` 守卫同款）。
- **根因**：`linkInputRegex` 无 `!` 前缀判别，敲 `![说明](路径)` 会被匹配 `[说明](路径)`（index=1），转换后残成 `!` + 半条链接，属"边敲边坏"。
- **测试**：`markdown-input.spec.ts` 加回归——`![图](url)` 保持字面不变；同段普通 `看 [docs](url)` 仍正常转链接（守卫生效不误伤）。
- **自检**：`vitest`（markdown-input + ime 共 33 项）全绿；`vue-tsc --noEmit` 退出 0。
- **回滚**：本阶段独立提交，`git revert` 即可。

## 3. Phase 3 · 拖入即互链（看落点，方案 B）✅（拖拽落点待真机验证）

- **决策纯函数**：新增 `wikilink-drop.ts` `decideDocumentDrop(paths, currentDocPath, isInsideEditor)` → `insert | open | none`。一期口径：仅「落在正文内 + 当前已保存 + 被拖为同目录 `.md/.markdown`」才 insert；`.txt` / 跨目录 / 未保存 / 正文外一律 open（安全默认=现状）。`isSameDirectory` 精确比较（宁漏判回落 open，不误链）。
- **接线四处**：
  - `MarkdownEditor.vue`：`handleDocumentDrop(paths, position)`（命中测试→决策→在光标处插 `wikilink` 节点）+ `isPointInsideEditor`（物理像素÷devicePixelRatio 后 `elementFromPoint` 命中 `.tiptap-editor`）；`defineExpose` 暴露。
  - `useAppWindowSession.ts`：新增可选 `requestWikilinkDrop`，drop 回调先问编辑器、被接住则不 open。
  - `useAppEditorState.ts`：`AppEditorExpose` 加 `handleDocumentDrop?` 类型。
  - `App.vue`：注入 `requestWikilinkDrop → editorRef.handleDocumentDrop`。
- **测试（四道锁）**：`wikilink-drop.spec.ts` 13 项覆盖 insert/open/none 各分支（正文内外、同/跨目录、.txt、未保存、混拖图片、多文件）。
- **自检**：全量 `bun run test` **1277 通过**、`vue-tsc --noEmit` 退出 0、`vite build` 成功（chunk 大小告警为既有、非错）。
- **⚠️ 未真机验证项**：拖拽落点 `position` 的类型（物理 vs 逻辑像素）、标题栏偏移——`isPointInsideEditor` 按「÷dpr + elementFromPoint」实现并已在代码注释标注。**失败模式非破坏性**：误判为「不在正文」→ 回落「打开」（现状）；误判为「在正文」→ 插入一条可撤销的链接，不写文件、不越界。需真机确认命中是否跟手，稳则收工、不稳则按方案改 Alt 兜底。
- **未做（守一期范围）**：悬停提示、子目录递归、跨盘/绝对路径、Rust 改动（同目录不需动 `list_markdown_files`）。
- **回滚**：本阶段独立提交，`git revert` 即可整体撤掉拖入功能、不影响 Phase 1/2。
