# solo Markdown 保真链路独立复核（2026-10-10）

> **只读审核**：本轮未改任何被测代码，未改任何现有文档。新形态已按纪律写成可直接粘贴的用例（见 §6），等一句话授权再回灌进 `roundtrip.spec.ts`。
> 判定口径：能用最小输入重跑的才算 `confirmed`；只能从代码推出触发条件、但入口在编辑/粘贴侧的算 `inferred`；查不到证据的写 `unknown`。

## 0. 一句话结论

**「打开 → 保存」在八类主流形态上是安全的（列表容器、后开先关、ZWNJ 文本+属性通道、代码区保护、链接路径、表格对齐、围栏升级、实体——都复跑过且没退化）；但这轮实测挖出 3 条 P0：同范围的行内代码会吞掉外层格式并让定界符变成正文文字、正文下一行直接写 `$$` 会让整块公式从文件消失、表格单元格里行内代码含裸竖线会让该行后半段从文件消失——第三条现有任何安全网都看不见。**

## 3. 「静默」与「开着就变形」要分开说

这条区分影响修复优先级，别混为一谈：

- **真静默（编辑器里看着完全正常，存一次才坏）**：#1 同范围 code、#9 href/src 的 ZWNJ、#8 alt 含括号、#14 target、#11/#13 字节类。**这几条最伤信任**，因为用户看不出「存进去的和屏幕上不是一个东西」。
- **开的时候就已变形，保存只是把损坏写进文件**：#2 段落紧接 `$$`、#3 单元格裸竖线、#4 callout 嵌套、#7 表格列数不等。模型里内容已经没了，所以肉眼/后续操作有概率发现。

**订正 5 —— F2 的真根因（实施中实测推翻了前两轮的推断，含 qoder 与本文 §8.0）**：

前两轮都写「`addNode` 的 `createAndFill` 返回 null 被静默跳过」。实测真机制是**三层**，缺一层都修不好：

1. **缺 token handler**：texmath 对「正文紧接 `$$`（中间不空行）」产出的**不是**块级 `math_block`，而是 **`math_inline_double`**（实测 token 流：`inline[text"正文", softbreak, math_inline_double]`）。solo 从来没有这个 handler ⇒ token 被**静默跳过**。
2. **`addNode` 不校验放置位置**：`createAndFill` 只校验「新节点装不装得下自己的 content」，**不校验它能否放进父节点**。于是 `mathBlock` 被直接 `push` 进 `inline*` 的段落。
3. **`closeNode` 的兜底是数据损失出口**：段落内容因此非法 ⇒ `createAndFill` 失败 ⇒ 走 `return this.schema.nodes.paragraph.create()`：**既不推回父节点、又丢弃整段已收集内容** ⇒ 连「正文」都消失（`- 项\n$$a$$` 的产物是 `- ` 空项）。

⇒ F2 的实现与两轮计划里写的都不同，是**三处**改动：补 handler + `addNode` 加放置校验 + `closeNode(expected?)` 加期望类型守卫、且兜底**绝不静默丢弃**。附带一条可复用事实：**`closeNode` 的「迟到 close」必须带期望类型**，否则 `addNode` 提前收掉段落后，`paragraph_close` 会误弹父容器；且 `bullet_list_close` / `list_item_close` 必须传**类型集合**（容器/项的类型是运行时才定的：`bulletList|taskList`、`listItem|taskItem`）——首版漏了这点，全量跑出 58 条红。

**订正 6 —— F5 必须成对做（实施中被自己的收敛断言抓住）**：只加 `escapeImageAlt`（写出侧）会让 `甲[乙` → `甲\[乙` → `甲\\[乙` **层层加反斜杠、永不收敛**（比原来的「丢图」更难察觉）。必须配 `unescapeImageAlt`（解析侧还原，因为 image token 的 `content` 是**原文**、转义未被处理）。

**批次 1 之后仍存在的已知缺口**（供批次 2/3 承接，均已实测）：① 容器内 `mathBlock` 续行缩进逐轮加深（qoder #5，→ F8）；② 脚注定义多段被并段（#6，→ F9）；③ callout 与嵌套引用互吃（#4，→ F6）；④ `KNOWN-ISSUES.md` 第 62 行那种「行内代码内嵌转义反引号」的畸形写法仍丢 318 个 code span（**未定位，unknown**，是当前 7 份体检变化里的唯一非噪声项）；⑤ 表格列数不等、围栏语言大小写、sup/sub 内多转义、空 frontmatter、link target 无载体（#7/#13/#11/#12/#14，→ 批次 3 / 登记）。
