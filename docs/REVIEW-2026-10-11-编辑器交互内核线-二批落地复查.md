## 3. 新查出的缺口（已登记，未修）

### 3.1 🔴 单元格里**任何**块级结构都「每存一次变一次」——#56 只收了 `heading` 一格 ⇒ 台账 §二 #60

`cellToText`（`serializer.ts:819-836`）只对 `paragraph` 走 `renderInline`，#56 给 `heading` 补了一个同款分支，**其余块级子节点仍走 `renderNode`** ⇒ 把块级语法写进单行容器。逐块型实测（生产 schema，R1 → R2）：

| 单元格里的块 | R1 | R2 | 收敛 |
|---|---|---|---|
| `bulletList` | `\| - 项 \|` | `\| \- 项 \|` | ✗ |
| `orderedList` | `\| 1. 项 \|` | `\| 1\. 项 \|` | ✗ |
| `taskList` | `\| - [ ] 项 \|` | `\| \- \[ ] 项 \|` | ✗ |
| `blockquote` | `\| > 块 \|` | `\| \> 块 \|` | ✗ |
| `codeBlock` | 三反引号围栏 + `js` | **降级成行内代码** | ✗（连围栏带语言名一起丢） |
| `callout` | `\| > [!NOTE]<br>> 块 \|` | 多两层转义 | ✗ |
| `mermaidBlock` | 三反引号 `mermaid` 围栏 | 降级成行内代码 | ✗ |
| `mathBlock` | `\| $$<br>x=1<br>$$ \|` | `\| $<br>x=1<br>$ \|` | ✗（重开后 `textContent` 为空；latex 是否落在 attrs 里**待单独定性**，我不下断言） |
| `heading` | `\| 标题b \|` | 同 | ✓（#56 已修） |

**可达性是关键**：这不是只有 HTML 粘贴才碰得到。光标放进单元格后 `toggleBulletList` / `toggleBlockquote` / `toggleCodeBlock` **实测全部接管成功**——**斜杠菜单与命令面板走的就是这三个命令** ⇒ 用户在单元格里选一次「无序列表」，从此这个文件每存一次变一次。文字本身不丢（`textContent` 前后一致），丢的是收敛性与块级语义。

**建议（唯一）**：把 `cellToText` 的 `else` 分支统一改成「拍平为行内文本」（与 #56 给 heading 的处理同款），并给 `roundtrip.spec.ts` Phase M 补一族级锁（每块型一条 R1===R2）。理由：GFM 单元格**根本表达不了块级结构**，任何保留块级语法的写法都必然不收敛；这是「内容保真 > 排版保真」的同一条取舍，#56 已经为 heading 认过一次。
**本轮未做**：属保真取舍（丢列表符号 / 围栏 / 语言名换一次收敛）+ 动 serializer 是敏感区（要跑全仓保真体检），**需简乐拍板**。

### 3.2 🟡 F4 残留一处误报：URL 紧跟中文时，后面的 `/` 被一起吞掉

`URL_CONTEXT_RE` 取「最后一个空白之后的整段」，而**中文没有空格** ⇒ 只要 URL 落在一个 token 的开头，这个 token 里后面的 `/` 与 `:` 全被吞。实测（纯函数）：

| 光标前文本 | 结果 | 该不该 |
|---|---|---|
| `参考https://x.com然后/` | 弹 ✓ | 对（token 以中文开头，没命中） |
| `，https://a.com的说明然后/` | 弹 ✓ | 对 |
| `https://a.com 然后/` | 弹 ✓ | 对（有空格断开） |
| **`https://x.com然后/`** | **不弹** ✗ | **误报** |
| **`详见 www.a.com然后/`** | **不弹** ✗ | **误报** |
| **`www.a.com然后/`** | **不弹** ✗ | **误报** |

**一行补丁（建议，本轮未动）**：把命中条件再加一个「触发字符的**前一字符**是 URL 字符」的合取——
`if ((char === '/' || char === ':') && isUrlContext(text.slice(0, charIndex)) && /[A-Za-z0-9._~:\/?#[\]@!$&'()*+,;=%-]/.test(text[charIndex - 1])) return null;`
按上表逐格推演：该挡的六格前一字符都是 `m` / `k` / `a` 等 ASCII ⇒ 照挡；三格误报的前一字符是 `后` ⇒ 放行。要动的话我再补 3 条锁 + 跑一次反向校准。
