# 快速上手

## 安装

1. 到 [Releases](https://github.com/jloft198479-cyber/solo/releases) 下载最新安装包（`x64-setup.exe`），支持自定义安装路径。
2. solo 使用系统自带的 WebView2 渲染，安装包很轻量；Windows 10/11 一般已内置。

## 首次启动

首次启动后建议到 **设置**（`Ctrl+,`）里开启 **Windows 文件关联**，之后就可以：

- 右键桌面/资源管理器 →「新建」→ Markdown 文档
- 双击 `.md` 文件直接用 solo 打开

> 文件关联、图标异常的排查见 [常见问题 FAQ](./常见问题FAQ.md)。

## 基本操作

| 操作 | 方式 |
| --- | --- |
| 新建 / 打开 / 保存 / 另存为 | `Ctrl+N` / `Ctrl+O` / `Ctrl+S` / `Ctrl+Shift+S` |
| 命令面板 | 菜单或状态栏入口，输入关键字快速执行命令 |
| 查找 / 替换 | `Ctrl+G` / `Ctrl+Shift+G` |
| 打开设置 | `Ctrl+,` |

完整快捷键见 [快捷键速查](./快捷键速查.md)。

## 多窗口

solo 是多窗口编辑器（v1.2.5+，不再使用单实例）：

- 每双击一个 `.md` 文件会启动一个独立窗口，各窗口互不牵连。
- 可以把两个文件并排摆放做对比编辑。
- 退出请走菜单「退出」：会向所有窗口发送关闭请求并逐窗口确认未保存内容；任一窗口点「取消」则中止退出。

## 自动保存

- 文档修改后 **2 秒自动保存**，直接写回原文件（不是临时副本）。
- 采用原子写：先写隐藏 `.tmp` 再改名替换，不会出现写一半损坏的文件。
- 手动保存走 `Ctrl+S`，保存有「乐观 UI」反馈——按下瞬间状态栏即显示已保存。

## 粘贴 Markdown

从其他编辑器（Typora / Obsidian / VS Code 等）复制 Markdown 文本粘贴进来，会自动转换为所见即所得格式；solo 扩展语法（Callout、公式、Mermaid、WikiLink 等）也能还原。复制出去时 `Ctrl+C` 会同时写入 Markdown 源码与 HTML，粘到别的编辑器不丢格式。
