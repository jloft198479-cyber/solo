# 快捷键速查

> 真理源是代码 `src/commands/registry.ts`（`defaultShortcut` 字段）。快捷键支持在设置中自定义；`Mod` 在 Windows 上是 `Ctrl`，macOS 上是 `Cmd`。

## 文件

| 功能 | 快捷键 |
| --- | --- |
| 新建文件 | `Mod+N` |
| 打开文件 | `Mod+O` |
| 保存文件 | `Mod+S` |
| 另存为 | `Mod+Shift+S` |
| 打开设置 | `Mod+,` |
| 退出 solo | `Mod+Q` |

## 历史

| 功能 | 快捷键 |
| --- | --- |
| 撤销 | `Mod+Z` |
| 重做 | `Mod+Shift+Z` |

## 行内格式

| 功能 | 快捷键 |
| --- | --- |
| 粗体 | `Mod+B` |
| 斜体 | `Mod+I` |
| 删除线 | `Mod+Shift+X` |
| 高亮 | `Mod+Shift+H` |
| 行内代码 | `` Mod+` `` |

## 标题与块级元素

| 功能 | 快捷键 |
| --- | --- |
| 一级 ~ 六级标题 | `Mod+1` ~ `Mod+6` |
| 普通段落 | `Mod+0` |
| 无序列表 | `Mod+Shift+8` |
| 有序列表 | `Mod+Shift+7` |
| 任务列表 | `Mod+Shift+9` |
| 引用块 | `Mod+Shift+Q` |
| 代码块 | `Mod+Shift+C` |

## 查找与视图

| 功能 | 快捷键 |
| --- | --- |
| 查找 | `Mod+G` |
| 查找和替换 | `Mod+Shift+G` |
| 复制为 Markdown（源码） | `Mod+Shift+M` |
| 焦点模式 | `Mod+Alt+F` |
| 全屏 | `F11`（macOS 为 `Mod+Shift+F`） |

## 表格操作

表格的行 / 列增删没有默认快捷键，通过「/」命令、菜单或命令面板使用：

- 在上方 / 下方插入行
- 在左侧 / 右侧插入列
- 删除当前行 / 当前列
- 切换表头行

## 特殊块删除

- **Mermaid / 数学公式块**：点击块进入代码编辑区后，`Mod+Backspace` 删除整个块（这类块是隔离区，标准退格不会删除整块）。
