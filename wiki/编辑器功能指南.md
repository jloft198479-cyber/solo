# 编辑器功能指南

## 所见即所得

solo 基于 TipTap / ProseMirror，**没有预览分栏**——输入 Markdown 标记（如 `# `、`- `、`**粗体**`）后回车或继续输入即自动渲染。也可以不记语法，用「/」命令或菜单完成一切格式操作。

## Slash 命令

在正文任意位置输入 `/` 呼出命令菜单，继续输入过滤（如 `/表格`），回车或点击插入。中文内容后面输入 `/` 同样有效（如「注意事项/」）。

## 扩展语法速览

| 语法 | 写法 | 说明 |
| --- | --- | --- |
| 数学公式（行内） | `$E=mc^2$` | KaTeX 渲染 |
| 数学公式（块级） | `$$...$$` 独占一段 | KaTeX 渲染 |
| Mermaid 图表 | ` ```mermaid ` 代码块 | 自动渲染流程图/时序图等；在块内文本区编辑代码 |
| Callout 标注块 | `> [!note] 标题` 引用语法 | 共 12 种类型：note / abstract / info / tip / success / question / warning / failure / danger / bug / example / quote |
| WikiLink 互链 | `[[文档名]]` | 输入 `[[` 弹同目录文件补全；单击跳转同目录目标文档（未保存提示先存、无扩展名自动补 `.md`、目标不存在可一键创建）；把**同目录**文档拖进正文即在**落点处**生成互链（拖到正文外、拖当前文档自身、或落点在代码块内仍是"打开"该文档） |
| Frontmatter | 文件开头 `---` 包裹的 YAML | 解析为文档元数据 |
| 脚注 | `[^1]` 标注 + `[^1]: 内容` 定义 | |
| 高亮 | `==文字==` | |
| 上标 / 下标 | `X^2^` / `H~2~O` | |
| 任务列表 | `- [ ] 待办` / `- [x] 完成` | 支持嵌套 |
| 表格 | GFM 管道语法 | 表头切换、行列增删见快捷键页 |

> 保存 / 重开文档后以上语法全部原样保留（roundtrip 保真），不会被「规范化」掉。

## 编辑辅助功能

- **查找替换**：`Ctrl+G` 查找、`Ctrl+Shift+G` 替换；跳转命中处有短暂高亮脉冲，方便定位。
- **大纲面板**：侧边栏展示全文标题结构，点击跳转；滚动时自动高亮当前所在章节。
- **字数统计**：状态栏实时显示（按中文字符 / 英文单词统计）。
- **焦点模式**：`Ctrl+Alt+F`，非当前段落变淡，适合沉浸写作；打印时自动恢复全部段落，不受影响。
- **文字变浅**（Dim）：给选中文字加变浅标记，可用于草稿标记。
- **Emoji 输入**：输入 `:` 呼出 emoji 建议。

## 输出

- **复制为 HTML**：状态栏 Copy 按钮，一键把当前文档（或选区）复制为富文本 HTML，跟随当前主题样式，可直接粘贴到公众号、邮件、Word。
- **打印**：菜单「打印」调用系统打印，可「另存为 PDF」。名称从旧版的「导出 PDF」改为「打印」是设计如此（实际走浏览器打印通道）。

## Markdown 源码互换

- **粘贴**：粘贴 Markdown 文本自动转换（见[快速上手](./快速上手.md#粘贴-markdown)）。
- **复制**：`Ctrl+C` 的 `text/plain` 通道始终是 Markdown 源码（含扩展语法），粘到任何纯文本编辑器都是合法 Markdown。
