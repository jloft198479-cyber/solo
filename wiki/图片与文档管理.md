# 图片与文档管理

## 插入图片

- **粘贴**：截图或复制图片后直接 `Ctrl+V` 粘贴。
- **拖拽**：把图片文件拖进编辑器窗口。
- **Markdown 语法**：`![说明](路径)`。路径可以是相对路径（相对文档所在目录）、绝对路径（如 `D:\photos\x.png` 的外部图片），或文档目录下 `assets/` 内的文件。

## 图片存储

- 在设置中可以指定**图片存储路径**（`imageStoragePath`）：粘贴 / 拖入的图片保存到该目录，Markdown 里以相对引用写入。
- 未设置时，图片按文档所在目录规则处理。
- **网络图片**：粘贴远程图片链接后，solo 会在本地缓存一份（应用数据目录下 `remote-image-cache/`），下次打开不再重新下载，断网也能显示。

## 自动保存

- 文档修改后 **2 秒自动保存**，直接写回原文件。
- 原子写：先写隐藏 `.tmp` 文件，再改名替换原文件——不会出现「写一半」的损坏状态。

## 崩溃 / 意外退出后的恢复

1. 先直接看原文件：自动保存写的就是原文件，多数情况无需恢复。
2. 若原文件异常，检查文档同目录下的隐藏 `.tmp` 残留（命名如 `.我的文档.1.tmp`），改回原文件名即为最近一次写入。
3. 崩溃残留的 `.tmp` 会在下次打开该文档时自动清理（超过 1 小时才视为残留），无需手动处理。

## 设置数据在哪

主题 / 字体等偏好存于：

```
%APPDATA%\com.solomarkdown\settings.json
```

solo 没有云端同步、也没有「最近文档列表」——单文件编辑器，多窗口各开各的。
