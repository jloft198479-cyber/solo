# 常见问题 FAQ

> 这里是速答；**完整排查步骤（含注册表操作）见真理源 [docs/TROUBLESHOOTING.md](../docs/TROUBLESHOOTING.md)**。

## 安装 / 文件关联

**Q：右键「新建」菜单出现两个 Markdown 项？**
旧版注册了 `.markdown` 和 `.md` 两个 ShellNew。卸载旧版 → 重启 → 安装新版（v1.2.3+ 安装时自动清理）。

**Q：`.md` 文件图标显示为空白？**
重新运行最新安装包即可，安装钩子会自动修复图标索引（`,0` 后缀）。

**Q：双击 `.md` 文件不打开 / 关联不生效？**
右键文件 → 打开方式 → 选 solo 并勾选「始终使用此应用」。重启 solo 会自动刷新关联。

## 编辑器

**Q：编辑器一直空白、不显示内容？**
编辑器是懒加载的，窗口获得焦点才创建。单击一下编辑器区域即可。

**Q：工具栏的「导出 PDF」按钮变成「打印」了？**
设计如此（v1.2.0+ 改名），实际走系统打印，可「另存为 PDF」。

**Q：创建了 Mermaid / 数学公式块，怎么删除？**
点击块进入代码编辑区后按 `Mod+Backspace`（Windows 为 `Ctrl+Backspace`）删除整块。这类块是隔离编辑区，普通退格不会删掉整块。

**Q：文档没改过，为什么显示「未保存」？**
如果遇到，请到 [KNOWN-ISSUES](../docs/KNOWN-ISSUES.md) 确认是否为已修复的旧版本问题，并升级到最新版。脏标判定已由「内容语义比对」接管，插件后台渲染不会误标。

## 窗口 / 进程

**Q：关闭所有窗口后进程不退出？**
多窗口架构下关闭最后一个窗口进程默认不退出。请走菜单「退出」，会逐窗口确认未保存内容后正常退出。若菜单无响应，在任务管理器结束对应 `solo.exe` 即可，不影响其他窗口。

**Q：编辑内容丢了？**
见 [图片与文档管理 → 崩溃恢复](./图片与文档管理.md#崩溃--意外退出后的恢复)。自动保存 2 秒直写原文件（原子写），先查原文件本身。
