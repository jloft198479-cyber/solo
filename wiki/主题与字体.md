# 主题与字体

## 内置主题（9 套）

在设置或主题面板中切换，明暗主题独立：

| 主题 | 风格 |
| --- | --- |
| Default | 默认中性配色 |
| Scholar Light / Scholar Dark | 书卷气浅色 / 深色 |
| Elegant | 典雅 |
| Cinnabar / Cinnabar Dark | 朱砂红浅色 / 深色 |
| Jade | 青玉 |
| Orchid | 兰紫 |
| Graphite | 石墨：近乎无彩的灰阶，层次全靠明度（取自 Vercel Geist 灰阶） |

- **配色与排版解耦**：主题只换颜色，**绝不改变行距、正文字号、字距、段距**。改主题时版式纹丝不动，这是硬规则。
- 支持**导入自定义主题**：设置 → 外观 → 「下载主题模板」，基于模板改色后导入。模板里还给了标题字号梯度与引用块边框宽度，想调这些局部视觉可以改；照抄不改则版式零变化。

## 字体（7 款）

| 字体 | 类型 |
| --- | --- |
| 系统默认 | system-ui，无需下载 |
| 微软雅黑 UI | 系统字体 |
| 思源宋体（Noto Serif SC） | 按需下载 |
| 朱雀仿宋 | 按需下载 |
| 小赖字体 | 按需下载 |
| 霞鹜文楷 Lite | 按需下载 |
| 汇文明朝 | 按需下载 |

- **按需下载**：除系统字体外，选中新字体会自动下载并缓存到本地，之后离线可用；下载失败会自动回退，不影响编辑。
- 编辑器与「复制为 HTML」导出共用同一套字体栈，保证导出内容和编辑器里看起来一致。

## 排版

solo 的排版参数分两层，**层级不同，负责的地方也不同**：

| 层级 | 包括 | 归谁管 |
| --- | --- | --- |
| **全文级** | 正文行高、正文字号、字距、段落间距 | **设置 → 编辑器**。主题改不到，也不该改 |
| **局部视觉** | H1~H6 字号梯度、引用块边框宽度 | 可由主题声明（模板里已给，值等于默认值） |

为什么要这样分：主题负责「长什么样」，设置负责「多大」。混在一起就会出现
「换个配色，行距跟着变、整篇文档变长」—— 这是刷墙刷到墙长高，不是设计。
（同一条原则见 VS Code：它的主题只管配色，字号行高是独立设置。）

另外，全文级四项归设置管：模板主题不再携带它们，设置里调过的字号 / 行高不会被模板主题冲掉。只有早期版本制作的、文件里自带整段排版参数的旧主题还能改这四项——遇到那种旧文件，按新模板重做一份即可。

### 改一个颜色会连带改什么

主题里的颜色按「语义」划分，少数颜色被多个元素共用。改之前先看这张表：

| 改这个 | 会连带改变 |
| --- | --- |
| `primaryColor` | 链接 / 光标 / 标题旁的 `#` 符号 / 待办勾选框 / 语法高亮关键字 / 选中文本底 / 脚注上标 |
| `textSecondary` | 引用块正文 / 图片说明 / 语法高亮的属性名 / 幽灵按钮 |
| `mutedColor` | 占位提示 / 折叠箭头 / 块删除按钮 / frontmatter / 菜单说明 / 删除线 / 语法注释 |
| `borderColor` | 代码块边 / 输入框边 / 弹窗边 / 滚动条滑块 |
| `sidebarBg` | **只有右侧大纲面板** |
| `surfaceAltColor` | 代码块工具条 / 数学块 / frontmatter / 图片占位 / 斜杠菜单图标 / 设置窗口底栏 |
| `listMarkerColor` | **只有列表前的小圆点与序号** |
| `tableBorderColor` | **只有表格线** |
| `quoteBorderColor` | **只有引用块左侧竖线** |
| `hrColor` | **只有水平分割线** |
| `selectionBg` | **只有选中文本的底色** |
| `markBg` | **只有高亮标记的底色** |
| `codeBorder` | 代码块与行内代码的边框 |

后 7 项是**零件级**开关，改它只影响那一处；前 5 项是语义色，本来就会被多处共用。

> `sidebarBg` 之所以只管大纲面板，是因为 `surfaceAltColor` 给了容器自己的底色。
> 若把 `surfaceAltColor` 那行删掉，容器会回退跟随 `sidebarBg`（老主题的兼容行为）。
