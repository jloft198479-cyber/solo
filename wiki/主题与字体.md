# 主题与字体

## 内置主题（8 套）

在设置或主题面板中切换，明暗主题独立：

| 主题 | 风格 |
| --- | --- |
| Default | 默认中性配色 |
| Scholar Light / Scholar Dark | 书卷气浅色 / 深色 |
| Elegant | 典雅 |
| Cinnabar / Cinnabar Dark | 朱砂红浅色 / 深色 |
| Jade | 青玉 |
| Orchid | 兰紫 |

- 每套主题不只换颜色，还带**独立排版参数**（行高、字号、段距、字距等），切换后编辑区有平滑淡入过渡。
- 支持**自定义主题**：可新建、编辑、导入、导出主题文件。

## 字体（7 款）

| 字体 | 类型 |
| --- | --- |
| 系统默认 | system-ui，无需下载 |
| 微软雅黑 UI | 系统字体 |
| 思源宋体（Noto Serif SC） | 按需下载 |
| 朱雀仿宋 | 按需下载 |
| 小赖字体 | 按需下载 |
| 霞鹜文楷 Lite | 按需下载 |
| 汇文明朝 | 按需下载 |

- **按需下载**：除系统字体外，选中新字体会自动下载并缓存到本地，之后离线可用；下载失败会自动回退，不影响编辑。
- 编辑器与「复制为 HTML」导出共用同一套字体栈，保证导出内容和编辑器里看起来一致。

## 排版

solo 的排版参数（行高、段距、字距、标题字号梯度）经过系统化设计校准，并与主题绑定。切换主题时如果觉得行距或字号变化，是主题自带的排版性格，不是 bug；自定义主题中可以单独调整这些参数。
