# 开发者入口

> 本页只是入口导引；**构建细节以 [BUILD_GUIDE.md](../BUILD_GUIDE.md) 为唯一真理源，架构以 [ARCHITECTURE.md](../ARCHITECTURE.md) 为唯一真理源**，此处不复制。

## 技术栈

Tauri 2（Rust）+ Vue 3 + Pinia + TipTap / ProseMirror + Tailwind CSS 4。纯本地应用，无后端。

## 环境搭建

需要：Bun、Rust 1.96+、MSVC Build Tools。

```bash
bun install
bun run dev          # 仅前端（Vite）
bun run dev:tauri    # 完整 Tauri 开发
bun run build:tauri  # 构建安装包
bun run test         # 测试（含 roundtrip）
```

编译不通过 → [BUILD_GUIDE.md §7 故障排查](../BUILD_GUIDE.md) / [docs/TROUBLESHOOTING.md](../docs/TROUBLESHOOTING.md)。

## 改代码的三条铁律（速记）

- **改 parser / serializer** 后必跑：`bun run test`（roundtrip）+ `vue-tsc --noEmit` + `bun run build`。
- **Rust 改动**必跑 `cargo check`（本地缺 MSVC 也不能跳过，CI 是最终闸门）。
- **新增 Rust 命令**三处同步：`commands/xxx.rs` 定义 → `commands/mod.rs` re-export → `lib.rs` `generate_handler!` 注册，且前端必须走 `command-names.ts` 真理源，禁止直接 `invoke('...')`。
